# Richerlink Router - Open Market Firmware

This is the Open Market Firmware for the Richerlink Router, providing enhanced functionality and customization options.

## Installation

You can install this firmware into the router using the router's web interface:

1. Connect to your router's web interface
2. Navigate to the firmware upgrade page by adding `upgrade.asp` after your router's IP address
   - Example: `http://192.168.1.1/upgrade.asp`
3. Select the firmware file and upload
4. Wait for the installation to complete

## Features

- Open source firmware implementation
- Enhanced router functionality
- Customizable settings and configurations

## Requirements

- Compatible Richerlink Router model
- Web browser for installation
- Stable power connection during upgrade

## Warning

⚠️ **Important**: Flashing firmware carries risk. Ensure you have the correct firmware file for your specific router model to avoid bricking your device.

## Command Line Access

To access the firmware upgrade page directly:

```bash
# Open your web browser and navigate to:
http://192.168.1.1/upgrade.asp
# Replace 192.168.1.1 with your router's actual IP address
```
